# Embedded Microcontroller Calculator

Embedded C calculator project using I2C communication and an LCD display.

## Tech Stack
- MCU: ATmega88PA
- Language: C
- Interfaces: I2C, LCD
- Build: Makefile

## Project Structure
- `main.c` – main code
- `i2c_master.c/.h` – I2C driver
- `lcd.c/.h` – LCD display functions
- `init.c/.h` – initialization routines
- `Makefile` – build/flash settings
- `Working calculator explaination.pdf` – documentation
